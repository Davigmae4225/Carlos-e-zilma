# Carlos & Zilma — Convite V2

Esta versão usa as 12 páginas/fotos do PDF enviado como galeria e foto de destaque.

## Personalizações pendentes
1. **WhatsApp:** abra `script.js` e substitua `5500000000000` pelo número que receberá as confirmações, no formato internacional.
2. **Lista de presentes:** no `index.html`, troque o `href="#"` do botão da lista pelo link real.
3. As fotos já estão dentro da pasta `imagens/`.

## Publicar no GitHub Pages
Envie `index.html`, `style.css`, `script.js` e a pasta `imagens` para um repositório. Depois, em Settings > Pages, selecione a branch principal e a pasta raiz (`/root`) para publicação.
